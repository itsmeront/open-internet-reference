# Suggest Content / Intake

Use this page to send a **lead** for processing — a URL, organization, case, or correction. You do not need to become a volunteer editor.

OIR is [human-directed and AI-processed](how-we-work.md): AI usually drafts the records; a human merges accepted work into the **draft corpus**.

## Fastest path: web editor

1. **Log into GitHub first** in the same browser: [github.com/login](https://github.com/login).
2. Open the editor: [openinternetresearch.com/admin/](https://openinternetresearch.com/admin/) (keep the trailing slash).
3. Tap **Login with GitHub**, approve access, then return to the editor.
4. Create a new Organization / Person / Law / Source record.
5. Fill in **Title**, **Summary**, and optional notes (paste links in the summary or body). You do not invent an ID.
6. Save — that opens a draft pull request for human review.

## Outreach CRM vs editor

The [Outreach CRM](../generated/outreach.md) is browse-only and needs no login. GitHub login is only for the content editor at `/admin/`.

## What happens next

1. AI or an editor processes the lead into draft source/knowledge records.
2. A human reviews and may merge into the draft corpus.
3. `verified` status, if ever, comes later from a separate deep source audit.
